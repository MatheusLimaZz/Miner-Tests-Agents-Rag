## Known Limitations

### Medium (via RSS)
- RSS feeds return only the most recent items (~10 per feed)
- **No historical coverage possible** via RSS
- The manifest records `truncated: true` and `historical_coverage: false`
- Medium does not offer a public search API

### LinkedIn
- **Permanently excluded.** No public content-search API exists
- Research/analytics on third-party content is not an approved use case
- Scraping is prohibited by platform terms
- The adapter exists only to record the documented exclusion in the manifest

### X / Twitter
- Read/search access requires a paid API plan
- The free tier does not include search endpoints
- Not on the critical path for v0

### Discord
- No global search API exists
- Bot API only reads servers where the bot is installed
- Requires privileged message content intent
- **Must have explicit admin authorization and ethical review**

### dev.to
- No full-text search API — collection is tag-based with local filtering
- Selection was performed locally, not by the API
